🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. CLONAR REPO
   git clone https://github.com/mesainteligentedemo-cell/victor-ia-agent.git
   cd victor-ia-agent

2. INSTALAR
   npm install

3. CONFIGURAR
   cp .env.example .env.local
   # Editar .env.local con credenciales

4. INICIAR LOCAL
   npm run dev
   # http://localhost:3000

5. DEPLOY A VERCEL
   vercel deploy --prod

6. IMPORTAR WORKFLOW N8N
   Dashboard → Import → n8n-workflow-vic-agent-v3.json

7. CONFIGURAR ELEVENLABS
   Agent Victor → Advanced → Post-call webhook
   URL: (webhook URL de N8N)

8. TEST
   Hacer llamada → Agent Victor → Esperar email
